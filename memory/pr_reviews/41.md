### F1: A missing index blob doesn't mark an excluded path whose content matches a checked-out file  (skipped)

- **severity:** Warning
- **status:** skipped
- **location:** starter/bin/_checks.py:398
- **concern:** Git stores blobs by content, so once a step writes a sparse-excluded path, whose bit Git then clears, a path whose committed content matches any checked-out file has its index blob present and isn't excluded. Reproduced with an emptied `.env` beside an empty tracked file: `--fetch-base` fetched `.env`'s base version, and the check reported the written `.env`.
- **resolution:** Deferred, not fixed. It needs a step that writes an excluded path, which no adopter has, plus content matching a checked-out file. The PR only adds exclusions over 3.9.1. The robust signal, the sparse patterns through `git sparse-checkout check-rules`, needs its own gating outside a sparse checkout.
- **follow_up_issue:** https://github.com/jubishop/project-starter/issues/43
